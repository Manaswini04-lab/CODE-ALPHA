# CodeAlpha Python Programming Internship

This repository contains the projects completed as part of my CodeAlpha Python Programming Internship.

## Tasks Completed

### Task 1 - Hangman Game
A simple text-based Hangman game developed using Python.

Features:
- 5 predefined words
- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect guesses
- Win and lose conditions

### Task 2 - Stock Portfolio Tracker
A Python program that calculates the total investment value of selected stocks.

Features:
- Stock price dictionary
- Stock name and quantity input
- Investment calculation
- Portfolio summary
- Total investment value

### Task 3 - Task Automation
A Python automation program that extracts email addresses from a text file.

Features:
- Reads a text file
- Finds email addresses automatically
- Saves extracted emails into a separate file
